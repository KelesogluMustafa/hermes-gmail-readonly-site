# hermes-gmail-readonly-site

Static homepage, privacy policy and terms of service pages for "Hermes Gmail Readonly",
a private personal automation that reads Gmail with read-only access.

- Live site (GitHub Pages): <https://kelesoglumustafa.github.io/hermes-gmail-readonly-site/>
- Files: `index.html`, `privacy.html`, `terms.html`

This repository is public because the Google OAuth consent screen requires publicly
reachable homepage, privacy policy and terms pages. It contains only these static pages;
no application source code, credentials or tokens are stored here.
