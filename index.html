Hermes Gmail Readonly

Hermes Gmail Readonly is a private personal automation that reads selected Gmail accounts with the Google Gmail API using read-only access.

The application does not send, delete, modify, archive, label, forward, or reply to email. Its purpose is to identify important messages and prepare personal summaries for the authorized account owner.

OAuth access is limited to https://www.googleapis.com/auth/gmail.readonly.
